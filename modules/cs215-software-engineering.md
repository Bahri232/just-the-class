## Module Overview
This course presents disciplined software engineering methodologies, tools, and processes required to build robust, scalable, and maintainable software systems. Students learn Software Development Life Cycle (SDLC) models, Agile/Scrum practices, requirements engineering, UML modeling, version control with Git, and software testing.

### Key Learning Outcomes
1. Compare and evaluate software lifecycle models (Waterfall, Spiral, Agile, Scrum).
2. Elicit, document, and validate functional and non-functional requirements.
3. Design object-oriented software architectures using UML notation.
4. Collaborate effectively in teams using Git branching and pull request workflows.
5. Apply unit testing, test-driven development (TDD), and integration testing.

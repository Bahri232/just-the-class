## Module Overview
This course examines the role of operating systems as resource managers and hardware abstraction layers. Topics include process creation, CPU scheduling algorithms, threads and concurrency, synchronization primitives, deadlocks, virtual memory management, and file system architectures.

### Key Topics
1. Operating System Structures, System Calls, and Kernel Architectures.
2. Processes, Context Switching, Inter-Process Communication (IPC).
3. CPU Scheduling (FCFS, SJF, Priority, Round Robin, Multilevel Queues).
4. Concurrency: Critical Sections, Mutexes, Semaphores, Condition Variables.
5. Deadlocks: Characterization, Prevention, Avoidance (Banker's Algorithm), Detection.
6. Memory Management: Paging, Segmentation, Page Replacement Algorithms (LRU, FIFO, Clock).
7. File Systems: Directory Implementations, Disk Allocation (Contiguous, Linked, Indexed), Disk Scheduling.
8. Linux CLI and Shell Scripting for Systems Administration.

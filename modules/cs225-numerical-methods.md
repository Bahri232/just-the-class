## Module Overview
This course investigates computational algorithms for solving mathematical problems that cannot be solved analytically. Students analyze sources of numerical error and implement algorithmic solutions in Python or MATLAB.

### Key Topics
1. Floating-point arithmetic, round-off errors, truncation errors, condition numbers, and numerical stability.
2. Root finding for non-linear equations: Bisection Method, Secant Method, Newton-Raphson Method, and Fixed-Point Iteration.
3. Solutions of Linear Systems: Gaussian Elimination, LU Decomposition, Jacobi Method, Gauss-Seidel Method.
4. Interpolation and Polynomial Approximation: Lagrange Interpolation, Newton's Divided Differences, Splines.
5. Numerical Differentiation and Integration: Trapezoidal Rule, Simpson's 1/3 and 3/8 Rules, Gaussian Quadrature.
6. Numerical Solutions to Ordinary Differential Equations (ODEs): Euler's Method, Modified Euler, Runge-Kutta Methods (RK4).
7. Computational implementation using Python (NumPy, SciPy, Matplotlib).

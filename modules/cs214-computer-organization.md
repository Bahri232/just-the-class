## Module Overview
This course examines the functional organization, hardware architectural design, and low-level execution models of modern computer systems. Key topics include digital logic, Boolean algebra, instruction set architectures (ISA), datapath design, memory hierarchy, and caching principles.

### Key Learning Outcomes
1. Analyze digital logic circuits using Boolean algebra, truth tables, and Karnaugh maps.
2. Design combinational and sequential logic circuits (multiplexers, adders, flip-flops, registers).
3. Understand instruction set architectures (RISC vs CISC) and assembly execution.
4. Explain CPU datapath, control unit pipelining, and hazard resolution.
5. Evaluate cache memory mapping, replacement policies, and virtual memory paging.

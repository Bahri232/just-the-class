## Module Overview
This course bridges the gap between software requirements and implementation by teaching rigorous object-oriented analysis and design (OOAD) techniques. Students master the Unified Modeling Language (UML), Gang of Four (GoF) design patterns, and architectural design principles.

### Key Topics
1. Object-Oriented Paradigms: Abstraction, Polymorphism, Inheritance vs Composition.
2. Requirements Analysis: Domain Modeling, System Sequence Diagrams, Operation Contracts.
3. Structural Modeling: Advanced Class Diagrams, Composite Structures, Package Diagrams.
4. Behavioral Modeling: Sequence Diagrams, Communication Diagrams, State Machine Diagrams, Activity Diagrams.
5. GRASP Principles: High Cohesion, Low Coupling, Controller, Creator, Information Expert.
6. Gang of Four (GoF) Design Patterns:
   - *Creational:* Singleton, Factory Method, Abstract Factory, Builder.
   - *Structural:* Adapter, Decorator, Facade, Composite.
   - *Behavioral:* Observer, Strategy, Command, State, Template Method.
7. Architectural Design Patterns (MVC, Layered, Hexagonal Architecture) and Code Refactoring.

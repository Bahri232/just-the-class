## Module Overview
This course introduces the concepts, principles, and techniques of relational database management systems (RDBMS). Students learn data modeling with Entity-Relationship (ER) diagrams, relational algebra, SQL querying, schema normalization, transaction management, and database application development.

### Key Learning Outcomes
1. Construct conceptual data models using Entity-Relationship (ER) diagrams.
2. Translate ER models into normalized relational schemas (1NF, 2NF, 3NF, BCNF).
3. Author complex SQL queries using joins, aggregations, subqueries, and window functions.
4. Understand database indexing, B-Trees, and query execution plans.
5. Apply ACID transaction properties and concurrency control techniques.

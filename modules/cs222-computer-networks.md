## Module Overview
This course provides a comprehensive top-down and bottom-up study of computer networks and the Internet. Students explore network layers, communication protocols, addressing and routing algorithms, and network security foundations.

### Key Topics
1. Network Architectures: OSI 7-Layer and TCP/IP 4-Layer Reference Models.
2. Physical & Data Link Layers: Transmission media, Framing, Error Detection (CRC), MAC Protocols, Ethernet.
3. Network Layer: IPv4 and IPv6 Addressing, Subnetting (VLSM, CIDR), ARP, ICMP.
4. Routing Algorithms: Distance Vector (RIP), Link State (OSPF), Border Gateway Protocol (BGP).
5. Transport Layer: Port Addressing, UDP (Connectionless), TCP (Connection-Oriented, Flow & Congestion Control).
6. Application Layer: HTTP/HTTPS, DNS, DHCP, SMTP, FTP, SSH.
7. Network Security: Cryptographic foundations, Firewalls, TLS/SSL, Virtual Private Networks (VPNs).
8. Network Simulation & Analysis with Wireshark and Cisco Packet Tracer.

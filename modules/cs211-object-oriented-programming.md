## Module Overview
This course transitions students from procedural programming to object-oriented programming paradigms using Java. Students will master object-oriented principles (encapsulation, inheritance, polymorphism, abstraction) and develop robust, maintainable software applications.

### Key Learning Outcomes
1. Understand and apply fundamental OOP concepts in Java.
2. Design and implement class hierarchies using inheritance and interfaces.
3. Master exception handling and input/output stream management.
4. Utilize the Java Collections Framework (List, Set, Map).
5. Build graphical user interfaces and handle event-driven interactions.
